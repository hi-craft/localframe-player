你的片库，随身的影院。

用 SideStore 安装 下载 IPA 文件

在 iPhone Safari 中打开。安装按钮会唤起已配置好的 SideStore；下载来自公开 GitHub 仓库，无需登录。也可打开版本页面获取文件。

使用你的 Apple 账号签名安装

请先完成 SideStore 配置并保持其所需连接。这个 IPA 尚未签名，点击安装后由 SideStore 下载、签名和安装；安装结果以 SideStore 的提示为准。

在手机上安装

  1. 点击「用 SideStore 安装」

    允许 Safari 打开 SideStore，按提示下载并使用原来给 Vela 签名的 Apple 账号更新。

  2. 需要时手动导入 IPA

    若安装按钮没有响应，点击「下载 IPA 文件」。下载完成后，在 SideStore 的 My Apps 中点击 +，从「文件」选择 IPA。

  3. 确认 build 15

    安装完成后打开 Vela，在设置中确认版本为 0.2.1 / build 15。手机上的签名与安装结果以 SideStore 的提示为准。

复现后，把日志发回来

进入 设置 → 诊断日志，先添加复现标记。出现整 App 卡顿时，等待 5–10 秒再强退重开，然后导出日志。请一并说明发生时间，以及是否使用外接 USB 存储。日志保留在本机，不包含视频内容、文件名或完整路径。
