下载日志版 IPA

请在 Safari 中打开。下载来自私有 GitHub 仓库，需要先登录有访问权限的账号。遇到 404 时，打开版本页面后再下载。

当前版本通过 SideStore 安装

这个安装包尚未签名，需要下载后交给 SideStore 签名。Safari 直接安装尚未开放，不能把下载成功当作安装完成。

在手机上安装

  1. 下载到「文件」

    点击上方按钮，确认下载。完成后可在 Safari 下载列表，或「文件」App 的下载项中找到 IPA。

  2. 使用 SideStore 导入

    打开已经配置好的 SideStore，进入 My Apps，点击 +，选择刚下载的 IPA。使用原来给 Vela 签名的 Apple 账号完成更新。

  3. 确认 build 14

    安装完成后打开 Vela，在设置中确认版本为 0.2.1 / build 14。手机上的签名与安装结果以 SideStore 的提示为准。

SideStore 官方安装指南 ↗

复现后，把日志发回来

进入 设置 → 诊断日志，先添加复现标记。出现整 App 卡顿时，等待 5–10 秒再强退重开，然后导出日志。请一并说明发生时间，以及是否使用外接 USB 存储。日志保留在本机，不包含视频内容、文件名或完整路径。
